GRUPO 6 - JUEVES NOCHE Titulo del proyecto: Viral Outfits Se desarrollará una aplicación web enfocada en el comercio electrónico. Como caso de negocio, el grupo construirá un e-commerce de indumentaria destinado a la compra de remeras, pantalones, calzado, abrigos y accesorios, ofreciendo todas las variantes, tallas y estilos para adaptarse a las preferencias del usuario. Como valor agregado y para impulsar las ventas, las visitas y la interaccion del usuario, se agregara un sistema de likes. Ofreciendo a los usuarios los "Outfits" mas "Virales" del momento.
